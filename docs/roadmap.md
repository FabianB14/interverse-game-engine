# Roadmap

## Version 0.1: Open the Editor and Make a Scene

User outcome: create a project, import art, place sprites, and run a scene.

Scope:

- Project manager
- Empty project template
- Project manifest and scene file format. Project manifest completed.
- Browser-reference runtime with a playable example scene. Completed.
- Asset browser
- Sprite rendering
- Basic transform tools
- Keyboard and mouse input
- Run button
- Example scene

## Version 0.2: Build a Complete 2D Game

User outcome: finish a small 2D game with menus, sound, saving, and export.

Scope:

- Collision
- Simple 2D physics
- Audio
- UI editor
- Animation
- Save and load
- Windows export
- Android export
- Sample complete game

## Version 0.5: Publish a Mobile Game

User outcome: prepare a commercial mobile game release.

Scope:

- Touch controls
- Mobile performance profiling
- App icons and splash screen flow
- Android packaging
- Optional plugin hooks for ads, in-app purchases, and analytics

## Version 0.8: Add 3D Foundations

User outcome: build simple 3D games without disrupting the 2D workflow.

Scope:

- 3D scene objects
- Cameras
- Mesh import
- Materials
- Lighting
- Basic animation

## Version 1.0: Stable Production Release

User outcome: ship professional projects with stable APIs and documented workflows.

Scope:

- API stability policy
- Migration tooling
- Full documentation
- Plugin system
- Testing and release automation
- Performance budgets
